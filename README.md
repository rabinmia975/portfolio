# Rabin Mia — Portfolio

Personal portfolio website of Rabin Mia, a full-stack web developer from Dhaka, Bangladesh.

**Live site:** https://rabinmia975.github.io/portfolio/

## Features
- Dark / light mode toggle (saved preference)
- Typing effect, scroll-reveal animations, animated skill bars
- Project filter by category, responsive design
- Tailwind CSS via CDN — no build step needed

## Tech
- Single static `index.html` (HTML5, vanilla JS, Tailwind CSS)
